# m5 · v0.5 — invisible

**Goal:** the fabric fades into the background. The tool already erased discovery
and addressing; this milestone erases the acts that remain — a pasted key, a
remembered start command, a machine that stutters when a peer lands on it — and
adds the first way to say "trust this one less." Config arrives here, opt-in and
layered, so nothing about the zero-config start changes.

Items are tracked in [`../registry.toml`](../registry.toml); live status in
[`../STATUS.md`](../STATUS.md).

## Items

- [`KN-CFG-050`] — the config file and its precedence ladder (flag > env >
  `~/.knit/config.toml` > default), written by a single `knit config` command.
  One command for every knob, so settings never become commands.
- [`KN-SCHED-051`] — share-time self-protection: reserve cores for the person at
  the keyboard, decline work on battery, step aside under interactive load.
- [`KN-AUTH-050`] — proximity pairing: a short code completes the key exchange
  over the discovered link, with no key on screen or clipboard.
- [`KN-AUTH-051`] — the first asymmetric trust: a machine that offers capacity
  but accepts nothing, or accepts only named peers.
- [`KN-OPS-050`] — the agent is on after install, not after a remembered command.

## Definition of done

- A new machine joins by pairing, not by pasting a key.
- A shared machine never takes the last core from its owner, and never takes
  work it should not (battery, heavy local use).
- A config file exists but is never required: delete it and only preferences are
  lost. Every setting has a correct default and a `knit config` equivalent.
- A machine can share capacity without granting execution.

## Theme

Everything here is about *absence*: fewer steps to join, fewer surprises while
sharing, fewer reasons to think about which machine. Config is the one addition,
and it earns its place by preventing a command per setting, not by adding one.
The transparent-offload endgame ([`KN-CORE-060`](../registry.toml), backlog) is
deliberately held until these foundations are in.
